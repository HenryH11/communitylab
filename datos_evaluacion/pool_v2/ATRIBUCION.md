# Atribución y licencias del pool v2

Estos archivos contienen texto de terceros, adaptado (limpieza, recorte y
anonimización de menciones) para evaluar el análisis de CommunityLab. No contienen
datos de usuarios de la comunidad del programa.

## `uca_ia_tweets.json` — CC BY 4.0

Guerrero-Contreras, G., Balderas-Díaz, S., Serrano-Fernández, A., y Muñoz, A. (2024).
*IA Tweets Analysis Dataset (Spanish)* [conjunto de datos]. Universidad de Cádiz.
Zenodo. https://doi.org/10.5281/zenodo.10821485 — Licencia
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Artículo asociado: *Enhancing Sentiment Analysis on Social Media: Integrating Text and
Metadata for Refined Insights*, IEEE International Conference on Intelligent
Environments (IE), 2024. https://doi.org/10.1109/IE61493.2024.10599899

Cambios: se quitaron enlaces, las menciones se reemplazaron por `@usuario`, se
recortaron los textos a 400 caracteres y se seleccionó una muestra de 200 tuits.

## `stackoverflow_es.json` — CC BY-SA

Preguntas de [Stack Overflow en español](https://es.stackoverflow.com), obtenidas con
la API pública de Stack Exchange. Cada caso incluye en `atribucion` el enlace a la
pregunta original, el nombre visible de su autor y su licencia (CC BY-SA 3.0 o 4.0,
según la fecha de publicación). Por la cláusula *Compartir Igual*, este archivo se
distribuye bajo la misma licencia.

Cambios: se tomó el título y el comienzo de la pregunta, los bloques de código se
reemplazaron por `[código]` y el texto se recortó a 400 caracteres.
