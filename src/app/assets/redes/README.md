# Logos de redes

Iconos de marca de [Bootstrap Icons v1.13.1](https://github.com/twbs/icons/tree/v1.13.1/icons),
distribuidos bajo la licencia MIT incluida en [LICENSE](LICENSE).
`x.svg` corresponde al icono original `twitter-x.svg`.

Se sirven localmente como mascaras SVG monocromas en los botones nativos de
Streamlit. No requieren conexiones a servicios de iconos. El nombre visible de
la red conserva la etiqueta accesible; el logo es decorativo y no implica
afiliacion con las plataformas.
